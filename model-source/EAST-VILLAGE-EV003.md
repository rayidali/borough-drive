## Changes

The browser shell now checks the complete base pack's expected size and SHA256 before starting the game. The expected identity is embedded into the shell by the exporter. A shell/pack mismatch during a release change offers the existing reload control and never starts a building-download wave. The pinned Godot 4.7.2 `init`, `preloadFile` and `start` APIs consume the verified bytes once; `startGame` would download the mutable pack again. [Pinned engine implementation](https://raw.githubusercontent.com/godotengine/godot/4.7.2-stable/platform/web/js/engine/engine.js).

An already-open game retains its embedded area catalog. Missing or corrupt old assets hold the current area; R retries the same release, and the status explains that a page reload opens the latest version. Retries request revalidation to avoid trusting a negatively cached response. The exporter still removes only obsolete files owned by the previous manifest; this does not promise indefinite availability of old releases. Model length/hash validation remains mandatory even for cached responses.

Hashed scene and manifest paths receive a one-year immutable browser cache policy. Mutable shells, build metadata, JS/WASM and the base pack revalidate. Local serving mirrors the policy and serves errors with `no-store`; Vercel configuration was compiled using the installed CLI's own routing utilities. This is local/configuration verification, not proof of candidate CDN headers. The [read-only production HEAD record](east-village-ev003/production-head-before.json) still shows the preceding monolithic revision09 package. [Vercel cache guidance](https://vercel.com/docs/caching/cache-control-headers) · [static header configuration](https://vercel.com/docs/project-configuration/vercel-json).

Window resizing now preserves the previous canvas projection and aspect while absent buildings load. Consecutive resize requests coalesce to the latest window size. Movement waits during the delayed case; the full viewport returns after readiness. This conservative bounded implementation reloads the twelve west models for any resize while they are absent. It does not shorten the camera range or substitute simpler scenery. Four camera modes and missing-file/retry were tested in actual Chrome. Image review exposed a reset interpolation sweep through intervening buildings; the camera now uses the actual car transform for a teleport frame, with normal driving interpolation preserved.
